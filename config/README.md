# Konfigürasyon örnekleri

Sadece sır içermeyen örnekler burada tutulur. development.example.json AlazHarness tasarım taslağıdır; OpenClaw veya Hermes'e doğrudan verilecek geçerli bir ayar dosyası olduğu iddia edilmez. Henüz bu dosyayı yükleyen veya sınırlarını uygulayan bir runtime yoktur.

Mevcut kullanıcı ayarlarını buraya taşımayın. Uygulama başlayınca ~/.hermes veya ~/.openclaw yerine proje runtime/ alanı açıkça yapılandırılacak. API anahtarları environment veya proje dışı sır deposunda kalacak; Git'e girmez.
