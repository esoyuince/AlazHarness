# Kanıt dizini

bootstrap/ yalnız çalışma alanı hazırlığının çıktıları içindir. JSON sonuçları, commit ve lisans hash'leri burada tutulur. Bunlar agent runtime veya MVP kabulü değildir.

Ham model konuşmaları, hesap sırları, büyük binary dosyalar ve kişisel veriler burada Git'e eklenmez. Geçici hacimli çıktılar artifacts/ altında kalır. Her sonraki iş kendi tarihli veya iş kimlikli kanıt dizinini kullanır.
